# Diagramas UML / UML diagrams

Os diagramas estão em formato **PlantUML** (`.puml`). É possível abrir e exportar as imagens com uma extensão PlantUML do VS Code ou com uma instalação local de PlantUML.

- `classes.puml`: classes de domínio e relações.
- `casos-de-uso.puml`: ações do operador.
- `sequencia-adocao.puml`: registro e aprovação de uma solicitação.
- `componentes-mvc.puml`: dependências principais entre camadas.

The diagrams describe the current code. They are editable text files. Export them to PNG or SVG if the teacher requires image files.
