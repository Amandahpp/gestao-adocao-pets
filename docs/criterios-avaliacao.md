# Critérios de avaliação — rastreabilidade

Este documento organiza as anotações da equipe. Confirme os requisitos exatos com o professor.

| Critério | Evidência no projeto | Verificação |
|---|---|---|
| C0 — Git/GitHub | `.gitignore`, organização de pastas, instruções no README | Conferir commits e participação no repositório remoto (não incluídos no ZIP) |
| C1 — Documentação | `docs/pt-br`, `docs/en`, diagramas `.puml` | Revisar linguagem controlada e diagramas com o professor |
| C2 — Padrões de projeto | Factory, Singleton e State nos modelos | Testes em `tests/test_models.py` |
| C3 — GUI | `src/views/` com Tkinter, eventos e layouts | Executar demonstração manual |
| C4 — Arquitetura | Separação MVC e decisões documentadas | Verificar imports e responsabilidades |

## Pendências de validação humana

- Verificar se o professor exige imagens exportadas dos diagramas além dos arquivos PlantUML.
- Confirmar o nível de aderência esperado a PTC, ASD-STE100 e Easy Read.
- Verificar histórico de commits, branches e contribuições reais de cada integrante no GitHub.
- Executar a GUI no computador usado na apresentação.
